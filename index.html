구현 명세서에 속아 시간을 낭비하던 경험은 이제 그만.
auto-docs는 Git Diff와 소스 코드를 직접 분석하여 최신 기술 문서를 GitHub & GitLab Wiki에 자동 배포합니다.

핵심 제공 기능

🧠

Google AI Studio Gemma4 연동

최신 Gemma4 LLM을 활용해 코드 변경 사항 및 모듈별 기술 요구사항을 높은 정밀도로 Markdown 렌더링합니다.

🔌

공식 mark3labs/mcp-go 규격

Stdio JSON-RPC 2.0 표준을 준수하여 확장 가능하고 안전한 Model Context Protocol(MCP) 환경을 제공합니다.

📚

GitHub & GitLab Wiki 자동 배포

웹 서버 구축 비용 없이 Wiki 저장소를 자동으로 Clone -> Commit -> Push하여 _Sidebar.md 네비게이션까지 관리합니다.

🔄

타 Repository 재사용 지원

GitHub Action (Mireu-Lab/auto-docs@v1) 한 줄 추가로 모든 프로젝트에 즉시 적용 가능합니다.

시스템 아키텍처

01

CI/CD Trigger

GitHub Actions / GitLab Runner / Jenkins에서 코드 Push 감지

➔
02

MCP Code Collector

Git Diff Analyzer 및 FileSystem Reader 도구가 소스코드 수집

➔
03

Gemma4 AI Synthesis

AI Studio LLM이 분석 결과 기반 마크다운 문서 생성

➔
04

Wiki Push

Home.md 및 _Sidebar.md 네비게이션 동기화 배포

기본 탑재 MCP (Model Context Protocol) 도구

Git MCP

git_diff_analyzer

HEAD~1 대비 파일 변경 목록 및 Git Diff 요약본 추출

base_ref: "HEAD~1"
FileSystem MCP

filesystem_reader

프로젝트 내부 소스코드 파일 내용 안전 조회 및 파싱

files: "pkg/agent/agent.go,main.go"

GitHub Actions 적용 방법

.github/workflows/auto-docs.yml
name: Auto Docs Wiki Generator

on:
  push:
    branches: [ main, master ]

jobs:
  generate-docs:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Run auto-docs
        uses: Mireu-Lab/auto-docs@v1
        with:
          gemini_api_key: ${{ secrets.GEMINI_API_KEY }}
          wiki_repo_url: "https://x-access-token:${{ secrets.GITHUB_TOKEN }}@github.com/${{ github.repository }}.wiki.git"
