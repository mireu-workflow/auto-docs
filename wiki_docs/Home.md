## 💡 Overview
`auto-docs` inspects your codebase git changes (`git diff`), runs MCP tools to extract source snippets, generates technical documentation using Google AI Studio / Gemma4 LLM, and automatically publishes the result to GitHub Wiki or GitLab Wiki.
